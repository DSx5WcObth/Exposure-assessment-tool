Exposure Assessment Tool

A Microsoft Excel-based calculation tool for estimating dietary exposure to agricultural chemical residues in foods, together with the files required for the calculation, is provided in this repository.

How to use the program
Unzip all split ZIP files (Exposure_assessment_tool_v13.zip.001–005) together.
Open the reconstructed Microsoft Excel file.
Enter the required data, including the processing factor, agricultural chemical name, and residue concentration detected in the food item (ppm), and select the appropriate food item number in the STFCJ and National Food Intake Survey datasets.
Start the calculation by clicking the “Start calculation” button. A summary of the calculated results will automatically be exported to the “Results” folder in the same directory.
