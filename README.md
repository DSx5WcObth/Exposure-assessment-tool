Exposure Assessment Tool
A Microsoft Excel-based calculation tool for estimating dietary exposure to agricultural chemical residues in foods, together with the files required for the calculation, is provided in this repository.

Important notice
This program and the accompanying files were developed for research purposes only.
The calculation tool incorporates processed data derived from a non-public national dietary survey. The underlying survey data were used with formal permission from the Ministry of Health, Labour and Welfare of Japan (MHLW).

How to use the program
1.	Unzip all split ZIP files (Exposure_assessment_tool_v13.zip.001–005) together.
2.	Open the reconstructed Microsoft Excel file.
3.	Enter the required data, including the processing factor, agricultural chemical name, and residue concentration detected in the food item (ppm), and select the appropriate food item number in the STFCJ and National Food Intake Survey datasets.
4.	Start the calculation by clicking the “Start calculation” button. A summary of the calculated results will automatically be exported to the “Results” folder in the same directory.
